Mode de paiement FedaPay —

Contrôle unique du mode de paiement pour tout le site (formulaire de paiement, vérification FedaPay, webhook). Aucune modification de code ni de configuration Vercel n'est nécessaire pour basculer : ce réglage seul suffit.

En mode LIVE, les paiements débitent réellement l'argent des apprenants. Les clés secrètes correspondantes (FEDAPAY_SECRET_KEY, FEDAPAY_WEBHOOK_SECRET) doivent déjà être configurées sur Vercel.

Espace apprenant / candidat —
