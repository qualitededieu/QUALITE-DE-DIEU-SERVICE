1. NOUVEAU DEPUIS TA DERNIÈRE VERSION EN LIGNE
---------------------------------------------------------------------
  ✅ Cachet du PDG encore agrandi (icons/signature-pdg.png, cachet +
     signature dans un seul fichier) : 560px de large maintenant
     (était 380px, puis 460px dans l'essai précédent). Toujours bien

  ✅ Message intelligent quand un numéro de dossier est reconnu mais
     que le téléphone ne correspond pas — pour la carte d'apprentissage
     ET l'attestation de fin de formation (GAS/carte.gs). Avant, dans
     ce cas précis, le site affichait le même message générique
     "Aucun dossier trouvé" que pour un numéro de dossier totalement
     inconnu — trompeur, puisque le dossier existait bel et bien.
     Le message dit maintenant clairement : "Numéro de dossier
     reconnu, mais le téléphone ne correspond pas." (+ le rappel du
     préfixe 01 si le numéro semble incomplet). C'était déjà le cas
     pour l'attestation de fin de STAGE (candidatures.gs) — c'est
     maintenant harmonisé partout.

  ⚠️ Ce lot-ci touche un fichier GAS (GAS/carte.gs) : il FAUT recopier
     son contenu dans l'éditeur Apps Script et redéployer une nouvelle
     version du Web App (voir section 3).
