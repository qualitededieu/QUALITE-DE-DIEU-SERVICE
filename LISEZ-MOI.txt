2. DÉPLOIEMENT GITHUB / VERCEL (le site)
---------------------------------------------------------------------
  1. Sur ton dépôt GitHub, remplace tout le contenu de la branche
     main par celui de ce zip (ou fais un commit qui écrase les
     anciens fichiers avec ceux-ci).
  2. Vérifie bien que le dossier js/ a été créé avec ses 4 fichiers,
     et que postuler.html est à la racine.
  3. Vercel redéploie automatiquement après le push.

---------------------------------------------------------------------
3. DÉPLOIEMENT GOOGLE APPS SCRIPT (le backend — IMPORTANT)
---------------------------------------------------------------------
  Le zip contient le dossier GAS/ à titre indicatif (utile pour tout
  reconstituer si besoin), mais l'éditeur Apps Script n'est PAS
  synchronisé avec GitHub — il faut y coller les fichiers à la main :

  1. Ouvre l'éditeur Apps Script de ton projet.
  2. Supprime le fichier "admin_regularisation.gs" s'il existe
     encore (c'est LA cause du bug qui empêchait tout de fonctionner).
  3. Remplace le contenu de admin.gs, carte.gs et code.gs par celui
     des fichiers du même nom dans GAS/ (ce zip).
  4. Ajoute deux nouveaux fichiers de script : candidatures.gs et
     chat.gs (copie leur contenu depuis GAS/ dans ce zip).
  5. Vérifie que init.gs et regularisation.gs sont identiques à ceux
     déjà dans ton éditeur (ils n'ont pas changé, mais autant
     confirmer qu'ils sont bien présents).
  6. Déployer > Gérer les déploiements > (crayon sur le déploiement
     existant) > Nouvelle version > Déployer.
     C'est cette étape qui active réellement tes changements sur
     l'URL Web App déjà utilisée par le site — sans elle, rien ne
     change côté utilisateur.
