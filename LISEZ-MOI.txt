Ce zip contient l'INTÉGRALITÉ du projet dans son état final. Tu peux
remplacer tout ton dépôt GitHub par ce contenu.

---------------------------------------------------------------------
1. NOUVEAU DEPUIS LE DERNIER ZIP — 4 corrections
---------------------------------------------------------------------

a) Panel admin "Régularisations" qui affichait "Erreur interne admin."
   Bug présent depuis le tout début du projet (avant toute intervention
   de ma part) : 4 fonctions admin pour gérer les régularisations
   n'avaient jamais été écrites. Corrigé dans GAS/admin.gs.

b) Recherche par téléphone (carte + attestation de stage) trop stricte.
   Un numéro tapé avec l'indicatif (+229, 00229) ou sans le "01"
   (nouveau format béninois depuis 2021, ex: 0197951230 au lieu de
   l'ancien 97951230) ne retrouvait pas toujours le dossier. Maintenant
   les deux formats sont reconnus comme équivalents dans les deux sens.
   Si la saisie ressemble à un numéro à 8 chiffres sans le 01, un
   message explicite le signale au lieu d'un simple "dossier introuvable".

c) Numéros de téléphone qui perdaient leur "0" de tête dans les Google
   Sheets (Google Sheets les convertissait en nombre). Toutes les
   feuilles (Toutes les inscriptions, Régularisations, Candidatures,
   RDV, Leads, Renseignements) forcent maintenant le format Texte sur
   la colonne téléphone à l'écriture.

d) PDF téléchargés vides pour l'attestation et la fiche apprenant (le
   PNG fonctionnait). Cause : l'ancienne méthode (html2pdf.js) prenait
   une "capture d'écran" d'une image encore en cours de chargement.
   Remplacé par une insertion directe de l'image déjà générée dans le
   PDF (jsPDF), sans étape de capture — la même méthode déjà utilisée
   avec succès sur verifier.html.

2. DÉPLOIEMENT GITHUB / VERCEL (le site)
---------------------------------------------------------------------
  1. Remplace tout le contenu de la branche main par celui de ce zip.
  2. Vercel redéploie automatiquement après le push.

---------------------------------------------------------------------
3. DÉPLOIEMENT GOOGLE APPS SCRIPT (le backend — IMPORTANT)
---------------------------------------------------------------------
  1. Ouvre l'éditeur Apps Script de ton projet.
  2. Vérifie qu'il n'y a PAS de fichier "admin_regularisation" (à
     supprimer s'il existe encore).
  3. Remplace le contenu de TOUS les fichiers .gs par ceux de GAS/
     dans ce zip (admin.gs, candidatures.gs, carte.gs, chat.gs, code.gs,
     init.gs, regularisation.gs) — cette fois-ci presque tous les
     fichiers ont changé, plus simple de tout remplacer d'un coup.
  4. Déployer > Gérer les déploiements > (crayon) > Nouvelle version >
     Déployer. Sans cette étape, rien ne change côté utilisateur.

---------------------------------------------------------------------
4. À VÉRIFIER APRÈS DÉPLOIEMENT
---------------------------------------------------------------------
  - Le panel "Régularisations" de admin.html affiche la liste des
    dossiers au lieu de "Erreur interne admin."
  - Recherche de carte/attestation avec un numéro saisi SANS le "01"
    (si le dossier a été enregistré avec le nouveau format) : le
    système doit soit trouver le dossier, soit expliquer clairement
    qu'il faut ajouter le 01
  - Un nouveau dossier (inscription, régularisation, candidature, RDV,
    chat) : le numéro de téléphone s'affiche bien avec son "0" de tête
    dans le Google Sheet correspondant (déjà existant : le 0 des
    anciennes lignes ne se corrige pas rétroactivement, seulement les
    nouvelles lignes à partir de maintenant)
  - Télécharger une attestation ou une fiche apprenant en PDF : le
    fichier n'est plus vide
