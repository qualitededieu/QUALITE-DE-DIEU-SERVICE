LES QUALITÉS DE DIEU SERVICE — Site complet, prêt à déployer
Mise à jour : attestation à deux signatures (Formateur + PDG)
=====================================================================

Ce zip contient l'INTÉGRALITÉ du projet dans son état final. Tu peux
remplacer tout ton dépôt GitHub par ce contenu.

---------------------------------------------------------------------
1. NOUVEAU DEPUIS LE DERNIER ZIP
---------------------------------------------------------------------
  L'attestation porte maintenant DEUX signatures/cachets, comme sur
  les vraies attestations LQD Service :
    - Formateur, à gauche (titre seul, pas de nom — variable selon
      la session)
    - PDG M. ATO Blaise, à droite ("Président Directeur Général")
  Le ruban "FORMATION VALIDÉE" est devenu une ligne compacte
  au-dessus des signatures, et le QR de vérification est passé dans
  le bandeau du pied de page (il occupait l'espace maintenant utilisé
  par les deux signatures).

  La fiche apprenant affiche aussi "M. ATO Blaise — Président
  Directeur Général" au lieu du nom de l'entreprise.

  Fichiers modifiés : js/attestation_generator.js,
  js/fiche_apprenant_generator.js

---------------------------------------------------------------------
2. IMAGES À AJOUTER POUR VOIR LES SIGNATURES/CACHETS
---------------------------------------------------------------------
  Le document se génère normalement sans ces fichiers (juste sans
  visuel de signature/cachet à la place). Pour les faire apparaître,
  ajoute dans icons/ :

    icons/signature-formateur.png   ← signature du formateur (gauche)
    icons/signature-pdg.png         ← signature de M. ATO Blaise (droite,
                                       utilisée aussi sur la fiche apprenant)
    icons/cachet.png                ← cachet officiel de l'entreprise
                                       (partagé entre les deux signatures)

  Aucun code à modifier, ces chemins sont déjà câblés.

---------------------------------------------------------------------
